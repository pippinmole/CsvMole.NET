# CsvMole Rewrite Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace CsvMole with a hand-written, spec-compliant `char` tokenizer (`net10.0`) plus an incremental source
generator that emits only model-specific binding code.

**Architecture:** `src/CsvMole` holds the runtime: `CsvReader` (a buffered tokenizer using `SearchValues`, sync and
async), the header-resolution helper, options, errors, converters and attributes. `src/CsvMole.SourceGenerators`
(`netstandard2.0`) turns each `[CsvParser]` partial method into a loop over `CsvReader` plus a shared synchronous
`TryBind{Model}` method. Problems are reported as diagnostics and the generator never throws.

**Tech Stack:** .NET 10, C# 14, Roslyn `IIncrementalGenerator` (Microsoft.CodeAnalysis.CSharp 5.9.0), NUnit 5,
Verify.NUnit + Verify.SourceGenerators (snapshots), BenchmarkDotNet, Sep, Sylvan, CsvHelper.

**Spec:** `docs/superpowers/specs/2026-11-05-csvmole-rewrite-design.md`. Read it before any task; this plan doesn't
repeat its behaviour tables.

## Global Constraints

- **NO COMMITS.** The user said not to commit. Leave all changes uncommitted in the working tree. There are no commit

  only strings, primitives, and `EquatableArray<T>`. Never an `ISymbol`, `SyntaxNode` or `Location`.
- Runtime library: zero package dependencies. Zero reflection on the parse path.
- Namespace for all public runtime types: `CsvMole`.
- Generated code: `// <auto-generated/>`, `#nullable enable`, every type name `global::`-qualified,

- Header matching: `StringComparison.OrdinalIgnoreCase`, after trimming the header cell.
- Default culture: `CultureInfo.InvariantCulture`. Never read `CultureInfo.CurrentCulture`.
- `MaxRecordLength` default: `1024 * 1024` chars.
- The local machine currently has only the .NET 8 and 9 SDKs (checked with `dotnet --list-sdks`). The .NET 10 SDK must
  be installed before Task 1 (ask the user; `winget install Microsoft.DotNet.SDK.10`).

## Review Focus

1. **`\r\n` split across a buffer refill** (`\r` is the last char of the buffer, `\n` is the first of the next). This
   must be one line ending, not an extra blank record. *Test: Task 3, `CrLfSplitAcrossBuffer`.*
2. **A UTF-8 BOM at the start of the text** (`"﻿Id,Name"` from a `TextReader` that didn't strip it). The header
   `Id` must still match `[CsvColumn("id")]`. *Test: Task 6, `Resolve_IgnoresLeadingBom`.*
3. **Very wide rows** (1,000+ columns, more than the initial field-boundary array). The array grows and every field is
   readable. *Test: Task 3, `WideRow_1000Columns`.*
4. **Stopping enumeration early** (`foreach … break`, or `.First()`). The pooled buffer is returned and the caller's
   `TextReader` is **not** disposed. *Test: Task 10, `BreakEarly_DoesNotDisposeCallerReader`.*
5. **The machine culture is `de-DE`** and the default options are used. `"1.5"` parses to `1.5m`, not an error or
   `15`. *Test: Task 10, `Default_IgnoresCurrentCulture`.*

### Task 3: `CsvReader` — the unquoted fast path (sync)

**Files:**
- Create: `src/CsvMole/CsvReader.cs`
- Test: `test/CsvMole.Tests/CsvReaderTests.cs`

**Interfaces:**
- Consumes: `CsvOptions`, `CsvError`, `CsvParseException` (Task 2).
- Produces:
  ```csharp
  public sealed class CsvReader : IDisposable
  {
      public CsvReader(TextReader reader, CsvOptions options, char delimiter);
      internal CsvReader(TextReader reader, CsvOptions options, char delimiter, int initialBufferSize); // tests
      public bool Read();                               // advance one record; false at end
      public int FieldCount { get; }
      public ReadOnlySpan<char> this[int index] { get; } // throws ArgumentOutOfRangeException if out of range
      public long LineNumber { get; }                   // 1-based physical line where the current record starts
      public CsvOptions Options { get; }
      public void Dispose();                            // returns pooled arrays; does NOT dispose the TextReader
  }
  ```

The approach: rent `char[]` from `ArrayPool<char>.Shared` and use `SearchValues.Create([delimiter, '"', '\r', '\n'])`
with `IndexOfAny`. Field boundaries go in a reused `int[]` that doubles in size when full. When a record crosses the
buffer end, shift the unconsumed tail to the front and refill. Grow the buffer (doubling) only when one record exceeds
it. Past `MaxRecordLength`, throw `CsvParseException(RecordTooLong)`. A trailing `\r` at the buffer end must wait for
the next refill before deciding whether it's a CRLF. Quote handling is a stub in this task: treat `"` as a literal
character (Task 4 replaces this).

  - `EmptyInput`: `Read()` is false.
  - `EmptyFields`: `"a,,c,"` gives `["a","","c",""]`.

- Test: `test/CsvMole.Tests/CsvReaderQuoteTests.cs`

**Interfaces:**
- Consumes: Task 3's `CsvReader`. The public surface doesn't change.

The approach: a field that starts with `"` (after skipping whitespace, but only when `TrimFields`) is quoted and ends
at the next `"` that isn't doubled. A field containing `""` is unescaped into a pooled scratch `char[]`, and the
indexer returns a span over the scratch buffer. A quoted field without escapes is a slice of the main buffer. A quote
in the middle of an unquoted field is literal. EOF inside quotes throws `UnterminatedQuote`, with `LineNumber` set to
the record's start line.

### Task 9: Emit sync parsers

**Files:**
- Modify: `src/CsvMole.SourceGenerators/Emit/ParserEmitter.cs`
- Test: `test/CsvMole.Tests/EndToEnd/SyncParseTests.cs`, `test/CsvMole.Tests/EndToEnd/Models.cs`

**Interfaces:**
- Consumes: `ModelInfo`/`MemberInfo` (Task 8), `CsvReader` (Tasks 3–4), `CsvHeader.Resolve` (Task 6),
  `CsvErrors.Report` (Task 2).
- Produces the generated shape, per parser class:
  ```csharp
  // per distinct model type:
  private static readonly string?[] __names_{Model}; private static readonly int[] __orders_{Model}; private static readonly string[] __members_{Model};
  private static bool __TryBind_{Model}(global::CsvMole.CsvReader r, int[] map, out {ModelFullName} model);   // sync, shared by sync and async
  // per distinct converter: private static readonly {ConverterFullName} __conv_{sanitised full name} = new();
  ```
  The sync method body, in this order:
  1. `options ??= CsvOptions.Default` (or use `CsvOptions.Default` if no options parameter).
  2. Create `using var r = new CsvReader(reader, options, options.Delimiter ?? '{attr or ,}')`.
  3. If `HasHeader`: when `!r.Read()`, `yield break`; then `map = CsvHeader.Resolve(r, …)`. Otherwise
     `map = CsvHeader.Resolve(null, …)`.
  4. `while (r.Read()) if (__TryBind_X(r, map, out var m)) yield return m;`.

  `__TryBind` parses each field into a local, then constructs: `new T(ctorArgs) { Init = local, … }`. On failure it
  calls `CsvErrors.Report(...)` and returns `false`. A column index `>= r.FieldCount` is `TooFewColumns`, unless the
  member `IsNullable` (or is `NullableString`), in which case the value is `null`. Parse calls follow the spec table,
  using `options.Culture` and `TryParse` forms.
